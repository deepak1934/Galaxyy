# 🌌 Galaxy Generator with Three.js

This is a 3D **Galaxy Simulation** project built using **Three.js**, where you can explore a procedurally generated spiral galaxy with animated particles, color gradients, and dynamic interactions.

## 🚀 Features

- Realistic **spiral galaxy** made of thousands of particles (stars)
- Customizable **parameters** like radius, spin, branches, and randomness
- Animated galaxy rotation
- Color gradients based on distance from the center
- Fully rendered using **WebGL** via **Three.js**
- Smooth performance and beautiful visual effects

## 🛠️ Tech Stack

- **Three.js** – For 3D rendering
- **JavaScript (ES6+)** – Main programming logic
- **Vite/Webpack/Parcel** *(optional depending on your setup)* – Development bundler
